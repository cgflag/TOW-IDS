## 2. 相较于最原始版本，我做的改动

从github上部署了TOW-IDS项目
原始版本问题：

数据处理逻辑不合原文，特别尺寸数据量过小

模型与论文存在差异

未能充分复现不同尺寸、不同subband、不同wavelet的对比试验

### 2.1 `run_pipeline.py`：新增一键执行入口
原始版本的问题：
- 缺少论文 Table-II 对比实验的统一入口，命令需要手动拼接。

我做的改动：
- 新增 `--mode table2`。
- 新增 `--table2-epochs`、`--table2-batch-size` 参数，并透传到 `table2_experiment.py`。
- 现在可以直接一条命令跑整套 Table-II 网格实验，降低操作复杂度。

### 2.2 `tow_ids_model.py`：增加了原始复现缺失的残差结构
原始版本的问题：
- 未复现原论文所说的残差
- 许多块少了一层可分离卷积层

我做的改动：
- 从 `Sequential` 重构为函数式 API（`layers.Input -> ... -> models.Model`）。
- `Block A` 改为双 `SeparableConv2D + BN + MaxPool`。
- `Block B` 明确引入残差分支 `Add([x, shortcut])`，并重复 5 次。
- `Block C` 保留分类头并和前面模块解耦，整体结构更清晰、更接近论文描述。

## 3. 工作
- Table-II 计划组合数：`45` 组（3 种小波配置 × 多尺寸 × 多层级）。
- 当前已完成并保存评估：`30` 组训练（`32/60/116/228` 窗口尺寸覆盖）。
- 两周内新增实验产物：
  - `models/table2`：`30` 个模型文件
  - `results/table2_eval`：`30` 个评估 JSON
  - `test_wavelet_transformed_data/table2`：`31` 个测试特征文件
  - `wavelet_experiments/cache`：`62` 个缓存文件
- 当前正在跑 `452x452` 相关组合（从 `31/45` 开始）。

## 4. 阶段结果（已完成 30 组）
- 当前最优：`one_wavelet_1_subband + 116x116 + Lv1`
  - `accuracy=0.9892`
  - `f_macro=0.9891`
  - `f_abnormal=0.9883`
- 明显异常点：`one_wavelet_4_subbands + 60x60 + Lv1`（`accuracy=0.4458`），后续会做复现实验排查。

## 5. 问题与解决
- 问题：大尺寸输入下 DirectML 存在稳定性风险（历史出现过 `DXGI_ERROR_DEVICE_RESET`）。
- 处理：
  - 在实验脚本内加入按尺寸自动降 batch 的保护策略。
  - 增加缓存复用和断点续跑，避免因中断导致整套实验重来。
- 现状：稳定性较之前有改善，但 `452x452` 仍需要跑完后统一评估。
